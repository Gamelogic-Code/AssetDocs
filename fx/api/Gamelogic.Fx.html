BoolKeyword

A serialized bool that drives a single shader_feature keyword when true. Subclass and override Keyword to name the keyword - the identity is code, not serialized data, so it can never drift from a renamed shader keyword.

EnumKeyword<TEnum>

A serialized enum that drives one shader_feature keyword from a fixed set, based on its current value. Subclass and override Keywords to name them (positional, matching the enum's underlying int values; use "_" for a value that maps to no keyword) - identity is code, not serialized data.
