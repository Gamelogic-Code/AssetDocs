Remarks

This effect needs four materials (its own MultiWash combine shader, the internal Gamelogic.Fx.WaterColor.PostProcessing.Effects.MultiWashProperties.Layer threshold shader used once per layer, the internal Wash shader, and Blur), so hosts (MultiWashPostProcess, GLMultiWashRendererFeature) run a bespoke multi-pass pipeline per layer: threshold (GetLayerThreshold(int), black level fixed at 0) → blur (horizontal then vertical) → wash (offsetting the noise texture per layer via GetLayerNoiseOffset(int) to decorrelate layers), then combine every layer's wash result via this effect's own shader, calling SetLayerTexture(Material, int, Texture) for each layer in use.

The per-layer threshold shader and its fixed black level of 0 are an internal implementation detail of the algorithm (not user-tunable, unlike the standalone Layer effect), so the threshold pass is not exposed as a serialized field here.

Remarks

Subclasses should override this method and set all relevant shader uniforms (for example, floats, vectors, colors, textures, and keywords).

Do not call IncMaterialVersion() here. By the time this method is called the material has already been fetched, so any increment would take effect one frame late. Staleness checks belong in CheckMaterialVersion().
