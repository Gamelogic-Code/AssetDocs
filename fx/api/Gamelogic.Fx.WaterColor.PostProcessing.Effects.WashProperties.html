Remarks

This effect needs two materials (its own Wash shader, and the internal Blur shader), so hosts (WashPostProcess, GLWashRendererFeature) apply this Properties instance across a bespoke multi-pass pipeline rather than the generic single-material PostProcess<T> pattern: blur the source (horizontal then vertical, using Blur), then blit with this effect's own shader, calling SetBlurredTexture(Material, Texture) to supply the blurred result.

Remarks

Subclasses should override this method and set all relevant shader uniforms (for example, floats, vectors, colors, textures, and keywords).

Do not call IncMaterialVersion() here. By the time this method is called the material has already been fetched, so any increment would take effect one frame late. Staleness checks belong in CheckMaterialVersion().
