Remarks

The fundamental region is the parallelogram spanned by basis vectors A = (x0, 0) and B = (x1, y1). It contains Count = x0 * y1 lattice points, each with a bias value stored in Matrix. The matrix is sized to the axis-aligned bounding rect of those Count points; positions inside the bounding rect but outside the parallelogram are filled with -1.

Call RecomputeBoundsAndReshape() after changing X0 or Point1 to resize the matrix and recompute the lookup dictionary. RebuildDictionaryIfNeeded() is called automatically before any read that requires the dictionary.

RecomputeBoundsAndReshape()

Recomputes the bounding box from the current params and reshapes the matrix to fit, preserving bias values at grid points that survive the resize. New region cells are set to 0; non-region cells to -1. Also rebuilds the lookup dictionary. Called automatically by the X0 and Point1 setters.

public void RecomputeBoundsAndReshape()
