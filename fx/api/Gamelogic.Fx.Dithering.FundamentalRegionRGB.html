Remarks

When Locked is true (All tab selected), R, G, and B all return All, and their setters throw InvalidOperationException. This lets all three channels share one region without destroying the per-channel data stored in Gamelogic.Fx.Dithering.FundamentalRegionRGB.regionR, Gamelogic.Fx.Dithering.FundamentalRegionRGB.regionG, and Gamelogic.Fx.Dithering.FundamentalRegionRGB.regionB.

When Locked is false (R, G, or B tab selected), each getter returns its own region and each setter copies via SetFrom(FundamentalRegion).
