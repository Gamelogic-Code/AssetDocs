Remarks

All functions use axial coordinates: the x component is the column axis and the y component is the row axis. This matches the coordinate system used by the Gamelogic/Fx/HexPixelate and Gamelogic/Fx/HexDitherGridBias shaders.

IndexToGridPoint(int, int, int, int)

Converts a fundamental region index to a hex grid point.

public static Vector2Int IndexToGridPoint(int index, int x0, int x1, int y1)

Parameters

index int

Index in [0, Count) where Count = x0 * y1.

x0 int

x-component of basis vector A.

x1 int

x-component of basis vector B.

y1 int

y-component of basis vector B (must be > 0).

Returns

Vector2Int

Remarks

The fundamental region is the parallelogram with basis vectors A = (x0, 0) and B = (x1, y1). It contains Count = |x0 * y1| lattice points with indices 0 .. Count-1. Rows run from y = 0 to y = y1-1; within each row y, the x0 columns start at ⌈y · x1 / y1⌉.

Assumes x0 > 0 and y1 > 0.
