Remarks

A ShaderProperties instance acts as the bridge between inspector-exposed settings and the underlying shader uniforms.

When enabled, this class attempts to load the shader specified by ShaderName and stores a reference to it so the shader is included correctly in builds.

Subclasses typically:
  1. Provide the shader name via ShaderName.
  2. Expose serialized fields that represent shader parameters.
  3. Override SetMaterialProperties(Material) to apply those parameters.
  4. Override CheckMaterialVersion() if any property change requires material recreation.

Properties

MaterialVersion

A generation counter that increments whenever the owning material must be destroyed and recreated.

public int MaterialVersion { get; }

Property Value

int

Remarks

Consumers (such as Gamelogic.Fx.BuiltIn.PostProcessing.PostProcess<TShaderProperties> and the Dither Designer preview renderer) each maintain their own "last seen" copy of this value. When their copy differs from MaterialVersion, they destroy their cached material and create a new one before the next render.

Do not increment this directly; call IncMaterialVersion() instead. See the block comment on the ShaderProperties source file for a full description of the material version system.

Methods

CheckMaterialVersion()

Checks whether any condition requires the owning material to be recreated, and calls IncMaterialVersion() if so.

public virtual void CheckMaterialVersion()

Remarks

The owning post-process calls this method at the top of each render, before fetching the effect material. This guarantees that staleness detection and material recreation happen in the same frame, with no visible lag.

Override this in subclasses whose properties can change size independently of normal inspector validation — for example, float arrays, texture arrays, or compute buffers whose element count is driven by user-editable data. Compare the current state against a stored "last seen" snapshot and call IncMaterialVersion() on a mismatch.

See Gamelogic.Fx.Dithering.PostProcessing.Effects.DitherMatrixBiasProperties for a worked example: it tracks each channel matrix's FloatMatrix.SizeVersion and increments the material version whenever any matrix is resized.

IncMaterialVersion()

Increments MaterialVersion, signalling all consumers that their cached material is stale and must be recreated before the next render.

public void IncMaterialVersion()

Remarks

Call this from CheckMaterialVersion() when a staleness condition is detected. Do not call it from SetMaterialProperties(Material) — by the time that method runs, the material has already been fetched, so incrementing there would defer recreation to the next frame.

OnEnable()

Called when the owning component or asset is enabled.

public virtual void OnEnable()

Remarks

The default implementation resolves the shader using ShaderName. Subclasses overriding this method should normally call base.OnEnable().

SetMaterialProperties(Material)

Applies all shader-related properties to the given material.

public virtual void SetMaterialProperties(Material material)

Parameters

material Material

The material created for the post process effect, using the shader defined by ShaderName.

Remarks

Subclasses should override this method and set all relevant shader uniforms (for example, floats, vectors, colors, textures, and keywords).

Do not call IncMaterialVersion() here. By the time this method is called the material has already been fetched, so any increment would take effect one frame late. Staleness checks belong in CheckMaterialVersion().
