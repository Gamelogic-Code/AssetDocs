How to manage the scale of screen-space textures

Get the base level scales.

  1. Adjust the clipping planes as tight as possible. Especially, the far clipping plane should be as close as possible.
  2. Set the material tiling to 1.
  3. On the RenderObjectInfo component,
    • set the object scale factor to 1:
    • Switch of compensate by scale and distance
  4. On the post effect:
    • Set the Scale of Screen-Space Textures to 1.
    • Switch off Use UV map.
    • Set texture tiling so it looks correct.

Decide which behavior you want.

Screen stable post effect: leave as is. Object stable - switch on Use UV map.

Now you can adjust the scale in several ways. If you want background objects to have the same texture scale as the foregrounds objects, you can either

  • Select Adjust by depth on the post effect.
  • Adjust by object distance on the RenderObjectInfo.

These use different mechanisms to approximate the same end result, and which looks best depends on your scene layout, camera movement, object movement, and so on.

Tweak for specific objects

On the RenderObjectInfo component you can select Compensate for object scale (if this is ticked, objects' scale should not affect the texture scale).

If your materials don't have textures, you can also scale the material texture.

Finally, set the background object tiling.

This depends on how far the far clipping plane is, and may be bigger than you think, depending how you want the texture to look. For a clip plane of ~100, the tiling may be on the order of (60,35).
