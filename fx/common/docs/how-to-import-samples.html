How to import samples

Quick import

The quickest way to import samples is to use the menu option Tools | Gamelogic | [Package] | Import Samples.

The samples will appear in a folder called Samples/[PackageName] in your project.

Import from the Package Manager

Alternatively, you can also use the package manager to import samples. Many packages use the same mechanism, so it is worth knowing about it.

Note

The layout of the package manager has changed a lot in details across versions of Unity. The instructions below may not be exactly correct for your version. However, the general idea should be the same, and you should be able to find the relevant buttons and tabs by looking around a bit if they are not exactly where described below.

Note

The package appears in multiple locations, and the samples tab is only visible in one of them!

Assuming the asset is already installed:

  1. Open the package manager.
  2. Navigate to the "In Project" tab to see the list of installed packages.
  3. Find the relevant package in the list, and select it.
  4. On the right-hand side you will see details about the package. There are tabs - select the "Samples" tab to see the list of available samples.
  5. Import a relevant sample by pressing the import button next to it.

The samples will appear in a folder called Samples/[PackageName] in your project.

Removing samples

Provided you did not use any of the assets (including scripts) from the samples in your project, you can simply delete the Samples/[PackageName] folder to remove the samples from your project.

If you did use some assets, (especially the pipeline asset and renderer), then move them to a different folder before deleting the samples folder, otherwise you will lose the reference to them and break your project.
