[2.0.1] 2026-03-07

🐞 Bug Fixes

  • Fixed a bug in ShaderProperty.SetOn where the IntegerArray case wrote into floatArrayValue assuming it was non-null and the correct size, which could cause a NullReferenceException or IndexOutOfRangeException at runtime.
  • Fixed a bug in ShaderPropertyThrowHelper.WarnIfExceeds where the argName parameter was declared as int instead of string, causing incorrect formatting in warning messages.
  • Fixed a bug in FxUtils.DestroyMaterial (URP branch) where the parameter was named shader and the body referenced an undeclared variable materialToUpdate instead of the material parameter.
  • Fixed a typo in PropertyNotfoundException — renamed to PropertyNotFoundException to match .NET conventions. The old name is kept as an obsolete alias.
  • Fixed an inconsistent class name: GLNormalMapRenderer has been renamed to GLNormalMapRendererFeature to match sibling classes. The old name is kept as obsolete.

🔧 Engineering

  • Updated to Extensions 4.6.0.

📄 Documentation

  • Updated documentation fixing typos and other errors, and adding missing documentation.

⬆️ Upgrade Notes

  • PropertyNotfoundException is now PropertyNotFoundException. The old name is obsolete and will be removed in a future version.
  • GLNormalMapRenderer is now GLNormalMapRendererFeature. The old name is obsolete and will be removed in a future version.
