Procedural Masked Post-Process Runner

Runs all post-process components found as children of a specified root transform, then composites the result onto the original image through a procedurally computed mask — either a half-plane or an ellipse. This lets you restrict an effect to one side of a line, or to an elliptical region, without authoring a mask texture.

For the texture-masked equivalent, see MaskedPostProcessRunner.

Note

All spatial parameters (Center, Softness, Radii) are expressed in aspect-corrected normalised screen-height units. A value of 0.5 always reaches half the screen height regardless of the display's aspect ratio.

Property Range Description
Post Process Root Transform The transform whose children are scanned for enabled post-process components. Components are run in child order.
Effect Strength [0, 1] Overall opacity of the composited effect. 0 shows only the original image; 1 applies the effect at full strength.
Mask Shape HalfPlane / Ellipse The procedural shape used to compute the mask.
Center ℝ² Centre of the mask shape in normalised screen coordinates (0,0 = bottom-left, 1,1 = top-right).
Angle ℝ (degrees) Rotation of the mask shape. For a half-plane, this rotates the dividing line; for an ellipse, it rotates the major axis.
Softness ℝ≥0 Width of the soft-edge transition in aspect-corrected normalised screen-height units. Larger values produce a wider, more gradual blend.
Invert true / false When enabled, the masked and unmasked regions are swapped.
Radii ℝ²≥0 Semi-axes of the ellipse in aspect-corrected normalised screen-height units. Only used when Mask Shape is Ellipse.

Mask shapes

HalfPlane — draws a line through Center at Angle degrees, masking everything on one side. Rotate the angle to reposition the dividing edge; use Softness to feather it.

Ellipse — draws an ellipse centred at Center with semi-axes given by Radii. Angle rotates the ellipse around its centre.
