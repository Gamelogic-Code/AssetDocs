Dither Grid Bias Designer

An editor window for interactively designing the dither matrices used by the Dither Grid Bias effect. Changes made here are applied live to the bound effect.

Open it from the Inspector of a Dither Grid Bias post-process component (the Open Designer button), or from the menu Window > Gamelogic > Fx > Dither Grid Bias Designer.

Layout

The window is divided into two panes side by side.

The Properties pane on the left shows the full set of grid bias dither properties. These are identical to the properties on the Dither Grid Bias effect — see that page for a description of each field. Edits here feed back directly into the bound effect.

The Preview pane on the right shows a live rendering that updates as you edit. A toolbar at the top switches between two views.

Toolbar

Control Description
Test Image Shows the effect applied to a generated test image. The test image and zoom level are set below.
Matrix Shows a four-quadrant greyscale visualization of the three channel matrices and their combined result (R, G, B, Combined). Renders via the dither shader itself with the TOOL_SHOW_BIAS keyword.
? Opens this documentation page in the browser.

Test Image controls

Visible when Test Image is active.

Control Description
Test Image Dropdown to select which generated test image to use as the preview source (gradients, colour ramps, etc.).
Zoom Scales the pixel size in the preview only, without modifying the bound properties. Useful for inspecting fine pattern detail up close.
Note

Pixelation is now a built-in property of the effect. Enable Pixelate in the Properties pane to preview the effect with the output snapped to the dither grid.
