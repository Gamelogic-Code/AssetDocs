[5.0.0] 2026-06-29

🎉 New Features

  • Added Dither Grid Bias effect — applies a data-driven dither bias using three independent per-channel floating-point matrices, snapped to either a hexagonal or rectangular pixel grid. See DitherGridBiasProperties.
  • Added Dither Grid Bias Designer — an interactive editor window for designing and previewing the dither matrices used by the Dither Grid Bias effect. Open it from the component Inspector or via Window > Gamelogic > Fx > Dither Grid Bias Designer.
  • Added Dither Grid Bias Texture Generator — an editor tool for baking the dither grid bias pattern to a texture. Open via Tools > Gamelogic > Texture Generation > Dither Grid Bias Texture Generator.
  • Both Dither Matrix Bias and Dither Grid Bias now include a built-in Pixelate property (bool, default true). When enabled, input UVs are snapped to the pixel grid before sampling, replacing the need for a separate Pixelate effect earlier in the stack.
  • Dither Grid Bias built-in pixelation now supports a Grid Angle property (±90°, inspector slider) to rotate the pixel and dither grid for both rect and hex modes. The 9×9 jitter antialiasing correctly preserves cell shape at all angles by operating in screen-pixel space.
  • Pixelation in all three effects (Pixelate, Dither Matrix Bias, Dither Grid Bias) is now anchored to the screen center rather than the corner. The grid is symmetric around the centre of the render target regardless of pixel size or rotation angle.
  • Pixelate now supports a Hex grid type (pointy-top hexagonal cells) in addition to the existing Rect mode, and exposes a Pixel Offset to shift the pixel grid.
  • Blend Texture now supports an optional mask: new Use Mask and Mask Texture properties let a greyscale texture control per-pixel blend strength.
  • Added Procedural Masked Post-Process Runner — composites a child effect stack through a procedurally computed mask (half-plane or ellipse), without requiring an authored mask texture.

⚙️ Editor Improvements

  • The Dither Pattern Designer and Dither Grid Bias Designer share a unified preview infrastructure, with a toolbar toggle between Test Image and Matrix views and a Zoom slider that scales the preview without modifying the bound properties.

🐞 Bug Fixes

  • FundamentalRegion now implements ISerializationCallbackReceiver; OnAfterDeserialize nulls the lookup dictionary so it always rebuilds from the correct deserialized state. Fixes stale-dictionary issues after domain reloads and Undo.
  • GridTypeFieldAttribute default hexEnumValue corrected from 0 (Rect) to 1 (Hex), fixing inverted Rect/Hex rendering in the inspector.
  • ResolveIsHex in FundamentalRegionDrawer and FundamentalRegionRGBDrawer now defaults to rect (false) when the conditional property is not found, instead of hex.

🔧 Engineering

  • Updated to Gamelogic.Fx version 5.0.0.

💀 Breaking Changes

  • Dither Pattern Generator texture tool has been renamed to Dither Matrix Bias Texture Generator. Find it under Tools > Gamelogic > Texture Generation > Dither Matrix Bias Texture Generator.

📄 Documentation

  • Updated dithering tips to reflect the new built-in pixelation workflow.
  • Fixed malformed DocFX alert boxes.
  • Corrected various spelling errors across effect and how-to documentation.
