Grid Bias Dither Designer

An editor window for interactively designing the dither matrices used by the Grid Bias Dither effect. Changes made here are applied live to the bound effect.

Open it from the Inspector of a Grid Bias Dither post-process component (the Open Designer button), or from the menu Window > Gamelogic > Fx > Grid Bias Dither Designer.

Layout

The window is divided into two panes side by side.

The Properties pane on the left shows the full set of grid bias dither properties — the same fields as the Inspector, including Grid Type, the per-channel matrices, pixel size, dither amounts, level count, smoothness, and UV mapping options. Edits here feed back directly into the bound effect.

The Preview pane on the right shows a live rendering that updates as you edit. A toolbar at the top switches between two views.

Toolbar

Control Description
Test Image Shows the effect applied to a generated test image. The image, zoom level, and pixelation toggle are set below.
Matrix Shows a four-quadrant greyscale visualization of the three channel matrices and their combined result (R, G, B, Combined). Renders via the dither shader itself with the TOOL_SHOW_BIAS keyword.

Test Image controls

Visible when Test Image is active.

Control Description
Test Image Dropdown to select which generated test image to use as the preview source (gradients, colour ramps, etc.).
Pixelation When enabled, applies a pixelation pass before dithering so you can preview how the pattern looks at the intended pixel grid scale.
Zoom Scales the pixel size in the preview only, without modifying the bound properties. Useful for inspecting fine pattern detail up close.
