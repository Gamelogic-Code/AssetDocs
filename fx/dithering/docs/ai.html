AI Skills

Gamelogic Fx ships AI Skills -- structured SKILL.md files that let Unity's built-in AI Assistant understand and drive this package's effects, map renderers, and tools directly from natural-language requests, instead of you having to know the exact component names and menu paths yourself.

Warning

🧪 Experimental. AI Skills are a new, actively-evolving feature of both this package and of Unity's own AI Assistant. Behavior, accuracy, and the exact setup steps may change between Unity versions. Treat any AI-driven change to your project the way you would treat any other automated edit -- review it before committing.

Getting it going

Unity's AI Assistant discovers skills automatically once it's installed and skills are allowed to run -- there's no manual step needed to "load" this package's skills beyond having the AI Assistant enabled in your project and pointed at a conversation that can see this package. Because the exact enablement flow (menus, preference toggles, permission prompts) lives inside Unity's own evolving AI tooling rather than this package, we don't document the click-by-click steps here -- consult Unity's own AI Assistant documentation for the current setup flow, then just ask it for what you want in plain language, using the kinds of prompts below as a starting point.

Example prompts

These exercise the core Gamelogic Fx skills directly -- map renderers, the general-purpose post effects, and the texture-generation tools:

  • "render a depth map for my scene and use it to drive an outline effect"
  • "make hatching/dithering follow surface curvature using a normal map" (see the Dithering/Cross-hatching examples below for the effect-specific side of this)
  • "add a blur, then posterize the result"
  • "generate a Voronoi texture I can use as a pattern"
  • "what post effects does gamelogic fx include for tone mapping?"

Example prompts for Dithering

  • "give my game a retro dithered look, classic bayer style"
  • "i want screen dithering in URP driven by my own blue-noise texture, not a built-in matrix"
  • "the dither pattern slides around when i move the camera, i want it to stick to the objects instead"
  • "i want a monochrome dithered look, but then recolor it back afterwards -- what's the right effect order?"
  • "i want to design my own dither matrix pattern for the effect on my camera, interactively"
  • "can you bake a hex-grid dither pattern to a png i can use with dither texture bias"
  • "does this project have dithering installed and set up correctly?"
  • "my UV-map dithering works fine in the editor but goes flat in the actual build, no idea why"
