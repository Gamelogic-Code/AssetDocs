Effects reference: WaterColor

Layer

Thresholds each color channel of the source image into a binary band mask: channels below Threshold are set to Black Level, channels at or above it are set to white. This is the first step of the watercolor pipeline — it picks out a single tonal band to be blurred and washed — but it is also useful on its own for simple posterized or silhouette looks.

Property Range Description
Threshold [0, 1] Each color channel below this value is set to Black Level; channels at or above are set to white.
Black Level [0, 1] The value assigned to color channels below Threshold.
Tip
  • MultiWash uses this shader internally, once per layer, with an evenly spaced threshold per layer and Black Level fixed at 0 — you don't need to configure it there. Add Layer as a standalone effect only when you want to inspect or reuse a single threshold band on its own.

Multi Wash

The complete watercolor effect. Thresholds the source into up to five evenly-spaced tonal bands (using Layer internally, one per layer), washes each band (using Wash internally, shared settings across all layers), then blends every layer's wash result together into a single organic watercolor look.

The per-layer threshold pass is entirely automatic — thresholds are spaced evenly across the tonal range and black level is always 0, so there is nothing to configure for it. Wash's blur and noise settings, however, are shared across every layer and fully configurable — see Wash above for the full property table (Blur, Noise Texture, Color Noise Scale, Shape Noise Scale, Power, Min Intensity, Max Intensity).

Property Range Description
Layer Count [1, 5] Number of tonal bands to threshold, wash, and blend together.
Tip
  • Start with a low Layer Count (2–3) — each extra layer adds a full threshold + blur + wash pass, so cost scales directly with it.
  • If the result looks too uniform, increase Wash's Color Noise Scale / Shape Noise Scale rather than Layer Count — the per-layer noise offset already decorrelates layers, so more layers mostly adds tonal richness, not variety.
  • The original watercolor effect this package is based on was designed to be layered with cross-hatching and an outline pass for a fuller painterly look. Both are separate effects in this Gamelogic Fx family (za.co.gamelogic.fx.crosshatching, SimpleOutline) and can be stacked manually, since MultiWash is a standard post effect like any other.

Wash

Blurs the source image and perturbs it with noise to produce an organic ink-bleed blotch. A single-layer building block used by MultiWash — also useful standalone, for tuning the wash look in isolation before combining multiple layers.

Blur

The source is blurred with a separable box blur (horizontal pass then vertical pass) before the wash noise is evaluated. Larger kernels produce softer, more spread-out washes.

Property Range Description
Kernel Size [0, ∞) The number of pixels sampled.
Kernel Offset (-∞, ∞) Where the kernel should start relative to the pixel. This is set by the shader internally to center kernels (even-sized kernels are 0.5 to the right of the center).
Jump Size (0, ∞) Multiplies the sampling step size. Use values greater than 1 for faster, softer blurs.

Wash

Property Range Description
Noise Texture 🖼️ Texture used to break up the wash boundary into an organic, ink-bleed-like edge.
Noise Tiling – Controls the tiling (scale and offset) of the noise texture.
Color Noise Scale (0, ∞) Strength of the noise applied to the wash color.
Shape Noise Scale (0, ∞) Strength of the noise applied to the wash shape/boundary.
Power (0, ∞) Exponent applied to the wash intensity. Higher values give harder-edged washes.
Min Intensity [0, 1] Minimum wash intensity.
Max Intensity [0, 1] Maximum wash intensity.
Tip
  • MultiWash offsets Noise Texture's tiling per layer (using a golden-ratio increment) on top of whatever offset is configured here, so the layers don't look identical — you don't need to manage that decorrelation yourself.
  • Tune Wash standalone first (feeding it a single Layer band) to dial in Color Noise Scale, Shape Noise Scale, and Power before combining layers in MultiWash — it's much faster to iterate on one pass than the full multi-layer pipeline.
