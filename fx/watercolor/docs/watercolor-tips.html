WaterColor Tips

MultiWash is the effect most people want — Layer and Wash are its internal building blocks, exposed as standalone effects so each stage can be tuned or debugged in isolation.

A good workflow:

  1. Add Layer on its own first, and adjust Threshold while watching the image, to get a feel for which tonal band(s) matter most in your scene.
  2. Add Wash on its own (feeding it a representative image) to tune Blur's Kernel Size, and Color Noise Scale / Shape Noise Scale / Power. This is much faster to iterate on than the full pipeline, since there's only one pass instead of one per layer.
  3. Once the single-layer wash looks right, switch to MultiWash and bring the same Wash settings across — they carry over directly, since MultiWash shares the same underlying Wash properties.

Kernel Size (under Wash's Blur) controls how far the ink appears to bleed. Larger kernels give softer, more spread-out washes, at a higher cost — the blur runs once per layer, so this cost multiplies with Layer Count.

Layer Count trades richness for cost directly: each layer is a full threshold + blur + wash pass. Two or three layers is often enough for a convincing result; each layer's noise is automatically decorrelated from the others (offset by a golden-ratio increment), so raising Layer Count mostly adds tonal richness rather than variety — if the result looks too uniform, try raising Color Noise Scale / Shape Noise Scale on Wash before reaching for more layers.

Min Intensity / Max Intensity control the darkest and lightest a washed layer can get. Narrowing the gap between them flattens the wash into a more uniform tone; widening it gives more contrast between the ink and the paper.

The original effect this package is based on was designed to be combined with cross-hatching and an outline pass for a fuller painterly look. Both are separate effects in this Gamelogic Fx family (za.co.gamelogic.fx.crosshatching, SimpleOutline) and can be stacked manually after MultiWash, since it's a standard post effect like any other.
